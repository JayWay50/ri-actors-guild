RI ACTORS GUILD GALLERY — one-time push from your computer
============================================================
Why: the gallery is 187 portraits (pictures). Our desk connection to
GitHub can only send text files, so this one push has to ride from
your machine. After it, Vercel deploys automatically, and text-only
updates (age fixes, wording) can go through the desk as before.

Steps (about 5 minutes, one time):
1. Download ri-actors-guild-gallery.zip from Riri and unzip it
   (right-click -> Extract All). You get this folder.
2. Open the folder and double-click PUSH-TO-GITHUB.bat
3. If it says Git is not installed: install once from
   https://git-scm.com/download/win (keep clicking Next - defaults
   are all correct), then run the .bat again.
4. If a GitHub sign-in window opens, sign in as JayWay50. Once only.
5. When it finishes, tell Riri. She checks the live page herself -
   187 cards, Gameli Awoonor at 49 - before calling it done.
